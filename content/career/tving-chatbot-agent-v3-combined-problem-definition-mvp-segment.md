# 통합 챗봇 에이전트(외부 바이럴 + 팬톡 리뷰 기반) — 문제정의와 MVP 세그먼트

## 핵심 요약 (두괄식)

두 기능은 서로 다른 신호(외부 바이럴 vs 내부 팬톡 리뷰)를 쓰지만, 둘 다 결국 **"지금 다른 사람들이 이 콘텐츠를 어떻게 보고 있는가"라는 사회적 증거(social proof)가 없어서 탐색이 막히는 문제**를 푼다는 점에서 하나의 문제정의로 묶입니다. 다만 두 신호를 처음부터 동시에 구현하면 범위가 넓어지므로, MVP는 **"이미 특정 콘텐츠에 관심을 보였지만 아직 시청을 시작하지 않은 사용자(탐색-고려 단계)"**를 1차 세그먼트로 좁히고, 이 세그먼트에는 기술적으로 더 검증된 **팬톡 리뷰 기반 기능을 먼저 적용**한 뒤, 외부 바이럴 추천은 "발견 자체가 안 되는" 더 넓은 세그먼트를 위한 2단계 확장으로 설계하는 것을 제안합니다.

---

## 1. 통합 문제정의

- **공통 문제**: 콘텐츠는 많지만, 사용자는 혼자 판단해야 해서 "이게 볼 만한 콘텐츠인지"에 대한 확신이 없어 탐색하다 이탈하거나 선택을 미룸
- **두 신호가 메우는 공백이 다름**:
  - 외부 바이럴 신호 → "존재 자체를 몰랐던 콘텐츠"를 발견하게 해주는 **발견(Discovery) 보조**
  - 내부 팬톡 리뷰 신호 → "이미 알고 있거나 고려 중인 콘텐츠"를 실제로 볼지 말지 결정하게 해주는 **결정(Decision) 보조**
- 즉 통합 문제정의는: **"탐색의 각 단계(발견 전 / 발견 후~시청 전)에서, 사용자 혼자서는 얻기 어려운 '타인의 반응'이라는 정보가 없어 콘텐츠 선택이 막히는 문제"**로 정리할 수 있습니다.

## 2. 두 신호의 역할 구분 (퍼널 단계별 매핑)

| 단계 | 사용자 상태 | 필요한 신호 | 담당 기능 |
|---|---|---|---|
| 1단계: 발견 전 | 뭘 볼지 전혀 모름(방향감 없음) | "요즘 뭐가 화제인가" | 외부 바이럴 트렌드 추천 |
| 2단계: 발견 후~시청 전 | 특정 작품을 알거나 고려 중이지만 확신이 없음 | "실제로 본 사람들 반응이 어떤가" | 팬톡 리뷰 기반 스포일러 방지 추천 |

## 3. MVP 세그먼트 제안 및 근거

### 제안: "2단계(고려 단계)" 사용자를 1차 MVP 세그먼트로 좁힌다

- **정의**: 특정 작품의 상세페이지에 진입했거나, 예고편·쇼츠를 보거나, 찜/관심 등록은 했지만 아직 시청을 시작하지 않은 사용자
- **이 세그먼트를 먼저 선택하는 이유**:
  1. **기술적 리스크가 낮음**: 팬톡 리뷰 기반 기능은 김현우(개발자)로부터 "기술적으로 명확하고 구현 가능성이 높다"는 평가를 이미 받은 반면, 외부 바이럴 크롤링은 API 정책·법적 리스크·실무 활용 방식에 대한 구체화가 아직 더 필요한 상태
  2. **측정이 쉬움**: 이미 관심을 보인 특정 작품이 있으므로, "리뷰 요약을 본 뒤 시청을 시작했는가"라는 명확한 전후 비교가 가능 — 1단계(방향감 없는 사용자)보다 인과관계를 깨끗하게 분리할 수 있음
  3. **전환 임팩트가 큼**: 이미 관심을 보인 "막판 confidence가 부족해 주저하는" 사용자는, 작은 넛지(리뷰 요약)만으로도 전환시킬 가능성이 높은 고효율 구간

### 외부 바이럴 신호는 왜 2단계로 미루는가

- 1단계(방향감 없는 사용자) 전체를 MVP 범위로 잡으면, 두 신호를 동시에 운영해야 해서 리스크가 커짐
- 팬톡 리뷰 기반 기능으로 먼저 "에이전트가 반응 데이터를 가공해 신뢰도 있게 보여주는 것"의 효과를 검증한 뒤, 같은 인프라(반응 데이터 수집 → 가공 → 노출)를 외부 바이럴 신호까지 확장하는 것이 안전한 순서

## 4. MVP 범위 (좁힌 흐름)

1. **대상**: 특정 작품 상세페이지 진입 또는 찜/관심 등록 후 24시간 내 미시청 사용자
2. **기능**: 챗봇 에이전트가 해당 작품에 대한 팬톡 내 실제 리뷰·반응을 수집해, 스포일러 요소를 제거한 "후킹 요약"을 생성해 제시 (예: "지금 팬톡에서 이 장면 때문에 난리났어요" 식의 비(非)스포일러 리뷰 요약)
3. **리스크 통제**: 스포일러 판별은 1차적으로 보수적인 규칙(결말·특정 반전 키워드 등 금지어 기반 필터링)으로 시작하고, 정확도가 검증되면 LLM 기반 판별로 고도화
4. **성공 지표**: 리뷰 요약 노출 후 시청 시작 전환율을 노출하지 않은 대조군과 비교(A/B 테스트)

## 5. 향후 확장 로드맵

- **1단계(MVP)**: 고려 단계 사용자 + 팬톡 리뷰 기반 결정 보조
- **2단계**: 같은 챗봇 에이전트에 외부 바이럴 트렌드 신호를 추가해, 방향감 없는 사용자(1단계 퍼널)까지 범위 확장
- **3단계**: 두 신호를 사용자 상태에 따라 자동으로 분기(이미 관심 작품이 있으면 리뷰 기반, 없으면 바이럴 기반)하는 통합 에이전트로 고도화

## 6. 면접에서 말할 때 한 문장

> "두 기능 모두 결국 '남들의 반응'이라는 사회적 증거가 없어서 콘텐츠 선택이 막히는 문제를 풉니다. 다만 한 번에 다 구현하면 리스크가 크기 때문에, 이미 관심을 보였지만 시청을 안 한 사용자에게 팬톡 리뷰 기반 기능을 먼저 검증하고, 그 다음 단계로 방향감이 아예 없는 사용자를 위한 외부 바이럴 추천까지 확장하는 순서로 MVP를 설계하겠습니다."
