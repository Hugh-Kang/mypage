# 티빙 CPO 2차 면접 1시간 전 브리핑

> 작성 목적: 실제 면접 1시간 전에 빠르게 훑어볼 수 있도록, 이 세션에서 준비한 전체 자료 중 가장 중요한 숫자·반복 지적 사항·필살기 답변·유일한 미준비 갭을 압축 정리
> 작성일: 2026-10-20
> 근거자료: `tving-cpo-2nd-interview-master-checklist-30.md` 외 이 세션의 career 디렉토리 전체

## 핵심 요약 (두괄식)

1시간 전 가장 중요한 세 가지는 ① **암기해야 할 핵심 수치**, ② **여러 모의면접에서 반복 지적된 습관(장황함·급격한 주제전환·비유 표현 사전설명)**, ③ **유일하게 미준비였던 KBO 라이브스포츠 질문에 대한 최소 방어용 답변**입니다. 나머지는 이미 충분히 다듬어져 있으니, 새 내용을 추가로 암기하기보다 아래 체크리스트로 "회상"하는 데 집중하는 것을 권장합니다.

---

## 1. 암기할 핵심 수치 (Cheat Sheet)

| 프로젝트 | 핵심 수치 |
|---|---|
| EV 숏컷 추천 고도화 | 즐겨찾기 15% 사용, 그중 85% 반복사용 / CTR 18%→25%(7%p) |
| 아이돌 챗봇 | 만족도 30%↑, 대화참여도(Linguistic/Interaction Cue) 각 25%↑ / AB테스트 100명, 5일 |
| 러닝보조서비스 | 크라우드펀딩 2.9만 달러, 반응 저조 → B2C→B2B2C/B2B 피벗 |
| 건강디저트 추천 | 네이버 스마트스토어 210개 상품 크롤링, 베타 출시 후 초기 MAU 1,300명(마케팅 없이) |
| 카카오T 결제수단 | "고아 결제수단" 문제 해결 → CS 월평균 0건 |
| 쿠폰 어뷰징 정책 | 쿠폰팩 2종류 발급으로 edge case·해킹 리스크 동시 해결 |
| AX 해커톤 | 제주 바다사막화 AI 모니터링 플랫폼으로 대상 수상 |
| KBO 중계권 | 2031년까지 계약 (티빙의 실제 자산) |

## 2. 반복 지적된 습관 — 이번엔 피할 것

| 지적 사항 | 바로 적용할 행동 |
|---|---|
| 자기소개·설명이 장황하고 중복됨 | 핵심 키워드 미리 정하고 한두 문장으로 압축, 뒤에서 또 반복하지 않기 |
| 질문이 여러 개일 때 일부만 답함 | 질문을 받으면 속으로 "몇 개를 물었지"부터 체크 |
| 급격한 주제 전환(스우파→건강디저트 등) | 전환 시 "건강디저트 프로젝트를 예로 들면"처럼 **연결 문장을 명시적으로** 넣기 |
| "고아 결제수단" 같은 본인만의 비유 표현 | 쓰기 전에 "제가 편의상 이렇게 부르는 건데"라고 먼저 밝히기 |
| MAU 등 수치를 말할 때 타임라인 모호함 | 본인 기여 구간과 결과 관측 구간을 분리해서 말하기("제가 설계·검증했고, 이후 팀이 출시해 이 수치가 나온 것으로 안다") |
| 통계적 엄밀성 질문에 방어적으로만 답함 | 한계를 먼저 인정하고, 보완 지표(응답지연·재방문빈도·정서강도 등)를 함께 제시 |
| "최소 공수로 최대 아웃풋" 같은 표현 과다 사용 | 다른 표현으로 분산(예: "정책으로 우회", "개발 범위를 좁혀서") |

## 3. 가장 강력한 필살기 답변 — 기회 되면 꼭 꺼낼 것

1. **PMF를 찾은 경험**: 버블의 비개인화 문제 → 채팅로그 분석으로 "실시간 정보에 대한 갈증"을 발견 → 솔루션 레벨에서 PMF를 찾은 서사
2. **쿠폰 어뷰징 정책 사례**: 개발 공수 없이 정책만으로 edge case와 보안 리스크를 동시에 해결 — 티빙에도 통신사 제휴 쿠폰·계정공유 같은 유사 사례 적용 가능
3. **네이버웹툰 해외성공 + 티빙의 실제 B2B 허브 전략 인지**: "자체 앱 직접 진출이 아니라 콘텐츠 허브 전략"이라는 점까지 안다는 것 자체가 차별화 포인트
4. **왜 채용해야 하는가**: 실행력(가설 검증+실패에서 배움) + 전략적 적합성(UX+데이터 복합 배경, CPO와의 공통점)

## 4. 유일한 미준비 갭 — KBO 라이브스포츠 (최소 방어용 답변)

> 이 질문은 사전에 충분히 다듬지 못했으므로, 아래는 즉석에서 쓸 수 있는 최소 방어용 뼈대입니다.

- **핵심 차이**: VOD 추천은 "이미 완성된 콘텐츠를 발견하도록 돕는 것"이지만, 라이브 스포츠는 "지금 이 순간의 경험을 풍부하게 돕는 것"이라는 점에서 역할이 다름
- **추천 관점**: "볼만한 콘텐츠 찾기"가 아니라, 경기 중 실시간 하이라이트·주요 통계 변화를 짧게 짚어주는 역할
- **챗봇 관점**: 라이브는 몰입을 깨면 안 되므로, 긴 대화형이 아니라 "짧고 즉답형"(예: 이 장면 다시보기, 이 선수 시즌 성적) 위주로 설계
- **팬톡 연계**: 실시간 팬톡 반응(예: 끝내기 홈런 직후 반응 폭발)을 하이라이트 자동 생성의 신호로 활용 가능
- **스포일러 개념 차이**: VOD의 스포일러(결말)와 달리, 라이브는 "다시보기 시청자에게 스코어를 언제 보여줄지"가 스포일러 이슈가 됨 — 기존에 설계한 스포일러 필터링 로직을 라이브/다시보기 맥락에 맞게 응용 가능하다고 설명
