## 2. 특히 잘 방어한 지점

| 항목 | 근거 |
|---|---|
| **p-value 0.05가 관례(convention)라는 핵심에 한 번에 도달** | 작년 실제 면접(`tving-2025-11-1st-interview-post-mortem.md` 3-5)에서는 재질문을 받고서야 도달했던 지점인데, 이번엔 첫 답변에서 바로 "사회적 약속"이라는 정확한 표현으로 답변함 |
| **DA 역할 재제안에 대한 "왜 필요한지 이해하면 기꺼이 한다"는 능동적 프레이밍** | `da-role-reproposal-defense-answer.md`에서 준비한 핵심 논리를 그대로 살려서 답변함 |
| **온톨로지 vs 벡터DB 차이를 정확한 언어로 구분** | "명확한 기준에 따른 정확한 답변 vs 맥락 기반 유연한 답변"이라는 핵심 구분을 스스로의 언어로 설명함 |
| **보안 기획 경험을 구체적 사례로 방어** | ISMS 심사 참여, CI 해싱 값 활용 설계 등 실제 사례를 즉석에서 정확히 제시함 |
| **장단점 답변의 구조와 구체성** | 강점(학습을 통한 직무 확장 — 건강 디저트 추천 플랫폼 MAU 1,300 달성)과 단점(급한 소통 → 킥오프 미팅으로 개선) 모두 사례 기반으로 답변함 |

## 3. 반복적으로 나타난 약점 패턴

| 패턴 | 발생 지점 | 개선 방향 |
|---|---|---|
| **질문의 일부만 답하고 나머지는 누락** | 챗봇 매출 연결 질문(2차 재질문 필요), 개인정보 유출 이슈 질문(본인 기여 의지 누락, 재질문 필요) | 질문이 두 부분으로 구성되어 있으면("A는 어땠나요, 그리고 B는요?") 반드시 두 부분 모두 답하고 있는지 스스로 체크하는 습관 필요 |
| **헤지 표현 후 선택("둘 다 잘할 수 있지만")** | Discovery 파트 선택 질문 | 결론을 먼저 말하고 그 다음에 근거를 붙이는 순서로 습관화 필요 — 작년 탈락 원인(3-8)과 동일한 패턴이므로 최우선 교정 대상 |
| **사실과 다른 기억을 자신 있게 말함** | 작년 DA 역할 제안에 "당연히 가능하다고 답했다"고 진술 — 실제 녹취록은 "둘 다 좋다"는 애매한 답변이었음 | 과거 사실을 말할 때는 실제 기록을 다시 한번 확인하거나, 확신이 없으면 "정확히는 기억이 안 나지만"이라고 정직하게 여지를 두는 것이 유리 |
| **압박 질문에 외부 요인으로 답을 돌림** | "저보다 핏이 맞는 사람이 뽑혔을 것" | 자기 성찰(내가 무엇을 잘못했는지)을 먼저 인정한 뒤 성장 포인트로 연결하는 순서가 더 설득력 있음 |
| **아이디어를 구조 없이 나열** | 서비스 개선 아이디어 질문 1차 답변 | "문제-트리거-출력-차별점-리스크 대응"의 미니 PRD 틀을 먼저 떠올리고 답변 시작하는 연습 필요 — 이번 세션에서도 코치 개입 후 일부만 개선(트리거·리스크 대응은 여전히 누락) |
| **이슈의 심각성을 가볍게 취급하는 톤** | 개인정보 유출 이슈에 "다른 회사도 극복했다"는 낙관적 톤으로 시작 | 민감한 이슈는 먼저 심각성을 인정하는 문장으로 시작한 뒤 낙관/기여 의지로 넘어가는 순서 필요 |

## 4. 이 과정에서 새로 확인/해결된 사실 (중요)

1. **홈화면 추천 CTR 프로젝트의 실제 검증 방법 확정** — MAU 24만 명 중 즐겨찾기 등록자 약 3만 명을 15,000명씩 무작위 두 그룹(공변량: 충전빈도·충전량·지역·연령대 균형화)으로 나눠 A/B 테스트를 진행했고, 카이제곱 검정에서 p<0.01로 유의미한 차이를 확인한 뒤 전체 확장 적용함. 포트폴리오 슬라이드에는 이 A/B 테스트 단계가 생략되고 전체 적용 이후 전후비교 결과만 실려 있었음. → `home-recommendation-ab-test-fact-resolution.md`에 반영 완료, `mock-interview-kimheejae-analysis.md`의 최우선 액션 아이템도 해결 처리
2. **ISMS 보안 심사 참여 경험 (신규 발굴)** — 이전 어떤 문서에도 기록되지 않았던 실제 경험. 보안 담당자와 함께 CI 해싱 값 활용 설계 등 최소 수집 원칙을 적용한 기획 경험. → `security-conscious-planning-experience-answer.md`에 반영 완료

## 5. 다음 단계 제안
