## (1) LG헬로비전 — AI 블러·검수 UX 설계

**기간**: 2026.04–07 · **참여 역할**: 주요 기능 설계 참여·피드백 · **협업**: PM(공동대표), 개발 리더(공동대표), 백엔드 1, AI 3 / 고객사 담당자

**요약**: 방송 편성심의 담당자가 영상 방영 전 PPL·브랜드 로고, 선정성·폭력성, 개인정보 노출, 블랙 프레임·미디어 노이즈 같은 편집 사고를 확인·처리하는 과정을 돕는 AI 블러·검수 기능의 주요 설계에 참여했습니다.

**문제**
- 90분 마스터 영상 한 편 검수에 약 1.5시간, 블러·후처리에 다시 약 1.5시간 — 총 3시간 이상 소요, PPL 집중 검수는 3~4일
- 선정성/폭력성/개인정보/브랜드로고 등 여러 탐지 유형이 한 화면에 섞여 구분 어려움, 블러 대상과 기술적 결함(블랙프레임·노이즈)도 미구분
- AI 오판정을 사용자가 직접 확인·수정할 방법 없음
- 민감도·로고 최소크기 등 처리 기준을 결과 확인 후에만 변경 가능해 재처리 필요
- 검수·블러 후에도 실제 후반 편집 툴(Premiere)로 재작업해야 해 검수·편집이 이중화

**역할 (참여·피드백)**
- 고객사 미팅 기반 문제·요구사항 정리에 참여, 전체 유저플로우(설정→AI처리→검수→내보내기) 설계에 참여
- 태그 기반 타임라인·장면 리스트 UI, AI 기준 사전설정+실시간 Preview UI, Premiere 내보내기 UX Writing 설계 논의에 참여하고 피드백, 고객사 시안 공유 및 개발팀 전달 과정에 참여

**구현 (주요 설계 참여 내역)**
- 8가지 탐지 유형을 색상 태그+필터로 구분, 블랙프레임·노이즈는 블러 대상과 시각적으로 분리
- 장면마다 8개 태그 버튼을 두어 사용자가 잘못된 판정을 직접 켜고 끌 수 있게 함(초기 "더보기" 메뉴 방식에서 변경)
- 처리 순서를 사후설정 → 사전설정(영상선택→블러처리→기준설정→AI처리→결과검수)으로 재설계, 로고 최소크기는 슬라이더+실시간 Preview로 체감 가능하게 설계
- 내보내기 방식을 "선택 장면 포함"에서 "제외"로 전환(고객 실제 작업 방식 반영), 확인 문구도 실제 처리 결과 기준으로 수정
- 블랙프레임·노이즈 구간은 Premiere로 넘어가면 마커로 자동 표시되도록 설계

**결과(사실)**: 위 설계(태그 타임라인·사전설정·실시간 Preview·내보내기 방식 변경·마커 표시)를 **기한 내** 완성해 개발팀에 전달, 제품에 배포. 배포 이후 검수 시간 변화·고객 반응은 별도 측정하지 않음(원본 명시).

**제안 성과 문구**
- "고객 문제로 확인된 3시간 이상 소요·최대 3~4일 걸리는 PPL 검수 병목(다중 탐지결과 혼재, 사후설정 재처리 구조)을 제거하는 방향의 설계에 참여"
- "8개 탐지 유형 태그 체계, AI 처리 사전설정 흐름, Premiere 연동 방식(마커 자동표시 포함)을 **기한 내** 완성해 개발 착수"

## (2) LiveNow — AI 영상 검색·편집 제품 설계

**기간**: 2026.04–06 · **참여 역할**: 주요 기능 설계 참여·피드백 · **협업**: 대표(PM), 개발 리더, 백엔드 1, AI 3 / 고객사 담당자 3

**요약**: 라이브커머스·홈쇼핑 고객사 LiveNow 요청에 맞춰 방송 영상에서 장면·출연자·상품 구간을 검색하고 숏폼으로 재가공하는 제품의 주요 기능 설계에 참여했습니다. 기능 추가로 복잡해진 흐름을 재점검·정리하는 과정에도 참여했습니다.

**문제**
- 기능이 AI 구간분할·AI 쇼츠생성·선택장면편집·블러처리 4개로 늘며 배치 혼선
- 쇼츠 제작 화면과 타임라인 편집 화면이 모두 컷 편집을 제공해 같은 작업이 두 화면에 중복
- 삭제가 아닌 "제외" 기능에 '휴지통'이라는 이름을 붙여 기능과 명칭이 어긋남
- 고객은 컷 편집보다 AI 자막 오타 수정을 주로 했지만 이를 빠르게 처리할 환경이 부족

**역할 (참여·피드백)**
- 화면 설계 논의 및 디자인 방향 피드백, AI 기능 추가에 따른 영상 상세 화면 기능 배치 설계에 참여
- 쇼츠 제작·AI 쇼츠 생성 옵션 흐름 설계 논의, 고객 인터뷰 참관·질문, 자막 편집 기능 설계에 참여, 개발팀 전달용 설계안·스펙 작성에 참여

**구현 (주요 설계 참여 내역)**
- "영상만 고르면 바로 쓰는 기능인가, 장면을 고른 뒤 쓰는 기능인가" 기준으로 헤더/탭 배치를 재설계(헤더 전체 배치안·탭 위계안 등 복수 시도 후 확정)
- 중복되던 쇼츠 제작 중간 화면을 제거해 **영상 선택→편집 화면 수를 3개에서 2개로 축소**
- AI 쇼츠 생성 흐름(유형 선택→구간/쇼츠길이/개수 설정→상품 선택→생성) 설계
- '휴지통' → '제외된 영상'으로 명칭을 바꾸고 위치도 인물 라벨 관리 화면 내부로 이동 — 재점검 과정에서 명칭·기능 불일치를 직접 발견
- 고객 인터뷰에서 확인한 요구(오타 수정 우선, 컷 편집 최소화)를 반영해 문장·장면 단위 자막 구조화, 클릭 재생, 임시저장·되돌리기, 자막 분할 기능 설계

**결과(사실)**: 위 기능 설계에 참여해 개발팀에 전달, 제품에 배포. **화면 수 3→2개 축소**는 확인 가능한 수치. 명칭 오류·중복 편집 단계는 재점검 과정에서 발견해 수정. 별도의 정량적 사용성 검증·개선 효과 측정은 진행하지 않음(원본 명시).

**제안 성과 문구**
- "영상 선택 후 편집까지 거치는 화면 수를 3개에서 2개로 줄여 조작 단계를 단순화하는 설계에 참여"
- "기능 추가 후 재점검 과정에서 명칭·정보구조 오류(휴지통 등)를 직접 발견해 출시 전 수정에 기여"

## 개별 프로젝트용 줄글 버전 (각 500자 이내, 복사-붙여넣기용)

### LG헬로비전 (468자)

방송 편성심의 담당자의 AI 블러·검수 업무를 돕는 기능을, 문제 정의부터 설계 제안까지 담당한 AI·UX 컨설팅입니다. 90분 영상 한 편 검수에 3시간 이상 걸리고 PPL 집중검수는 3~4일이 걸리는데, 여러 탐지유형이 한 화면에 섞여 구분이 어렵고 AI 오판정을 고칠 방법이 없으며 처리 기준을 결과 확인 후에만 바꿀 수 있어 재처리가 반복되고 검수 후 Premiere로 다시 작업해야 하는 이중화까지 겹쳐 있었습니다. 고객사 미팅에 참여해 문제를 정리하고 전체 유저플로우와 화면 설계 방향을 제안했으며, 시안을 고객사와 공유하고 개발팀에 전달하는 역할을 맡았습니다(실제 구현은 개발팀 담당). 8개 탐지유형 태그·필터 체계, 처리 기준의 사전설정 전환과 실시간 Preview, 내보내기 방식을 포함에서 제외로 전환, Premiere 마커 자동표시를 제안했고, 이 설계안을 기한 내 완성해 개발팀에 전달해 제품에 반영·배포됐습니다.

### LiveNow (471자)

라이브커머스 고객사의 AI 영상검색·숏폼 편집 제품에서, 기능 추가로 복잡해진 흐름을 재정비하는 컨설팅에 참여했습니다. 기능이 4개로 늘며 배치가 혼선되고, 쇼츠 제작 화면과 타임라인 편집 화면이 같은 컷 편집을 중복 제공했으며, 삭제가 아닌 제외 기능에 '휴지통'이라는 오해 소지 있는 이름이 붙어 있었고, 고객의 실제 주요 작업인 자막 오타 수정을 빠르게 처리할 환경도 부족했습니다. 고객 인터뷰에 참관해 요구사항을 확인하고 화면 설계 방향을 논의·피드백했으며, 개발팀 전달용 설계안 작성에 참여했습니다. 영상만 고르면 바로 쓰는 기능과 장면을 고른 뒤 쓰는 기능을 구분해 배치를 재설계하고, 중복되던 쇼츠 제작 화면을 없애 편집까지 거치는 화면을 3개에서 2개로 줄였으며, '휴지통'을 '제외된 영상'으로 정정하고 자막 편집 기능을 제안했습니다. 그 결과 화면 수 축소와 명칭 오류 수정을 반영한 설계안을 기한 내 개발팀에 전달했습니다.
