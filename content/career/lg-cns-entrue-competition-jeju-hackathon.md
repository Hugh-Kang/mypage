# 공모전 활동내용 — 제주 바이오 AX 해커톤 대상

> 대회: 2026년 제주 바이오 AX 해커톤 (주최: (재)제주테크노파크)
> 수상: 대상 (2026.7.11, 제2006-200호)
> 팀명: 블루마린스 (천주용·최훈석·강해우, 3인)
> 서비스명: 갯아웃 — 제주 다이버 수중 영상 기반 갯녹음 위험지수 플랫폼
> 근거: 발표자료(19슬라이드) 전체 텍스트 + 수상 상장

## 활동내용 (배경 · 목적 · 역할 · 구현 · 결과 · 의의)

**배경**
갯녹음(바다사막화)은 해조류가 사라지고 석회조류가 암반을 덮어 하얗게 변하는 현상으로, 제주 연안 암반의 39.53%(64.84㎢)에서 발생 중이며 건강기능식품 원료인 모자반·감태 생산량이 약 95% 감소해 수입 의존도가 심화되고 있습니다. 그런데 인력·자원 부족으로 갯녹음 조사 주기가 2~3년에 달해, 매년 약 300억원의 복원 예산이 이미 심화된 해역에 투입되며 회복 가능한 해역의 골든타임을 놓치는 문제가 반복되고 있었습니다. 한편 다이버들은 특정 다이빙 포인트를 반복 방문하며 갯녹음 진행을 가장 먼저 목격하지만, 이를 조사기관에 제보할 채널이 없었습니다.

**목적**
"갯녹음 조사 주기가 길고 파악·공유가 늦어 회복 가능 해역의 골든타임을 놓친다"는 문제를 재정의하고, 다이버가 일상적으로 촬영하는 수중 영상을 활용해 갯녹음 위험도를 실시간으로 분석·시각화하는 플랫폼을 만드는 것을 목표로 삼았습니다.

**역할 분담 및 본인 역할**
3인 팀으로 역할을 나누어 진행했습니다.
- 천주용(팀장): AI·백엔드 — 수중 생물(성게) 객체 탐지 모델 구축, 공공 API 연동
- 최훈석: 디자인·프론트 — 화면 디자인, 웹 대시보드 개발
- **강해우(본인): 기획** — 다이빙 커뮤니티 및 문헌 조사, 문제 정의, 서비스 기획 총괄(위험지수를 구성할 지표 선정과 가중치 설계 방향 제시, 로드맵 설계 포함)

**구현**
- **수온**: 해양수산부 국립해양조사원 조위관측소 API로 제주 인근 4개 관측소(제주·서귀포·성산포·모슬포)의 실측 수온을 조회해, 영상 촬영일·촬영 위치에 가장 가까운 관측소 수온을 다이빙 포인트별로 매핑
- **성게 밀도**: YOLO 기반 객체 탐지·의미론적 분할 모델로 수중 영상 속 성게를 탐지해 단위 면적당 개체수 산출 (참조 데이터셋: 77,470장 이미지 내 327,690개 성게 객체 — 팀이 학습에 활용한 공개 데이터 규모이며, 자체 모델의 정확도 수치는 발표자료에 별도로 없음)
- **해조류 피복률**: Vision LLM으로 영상 프레임에서 해조류·암반·모래를 구분해 해저 면적 대비 해조류 비율(피복률) 산출
- **위험지수 산출**: 수온 상승(40%) + 성게 밀도(30%, 2개체/㎡ 초과 시 자연회복 불가 임계점 반영) + 해조류 피복률(30%, 역방향 지표) 가중합으로 갯녹음 위험지수 계산
- **핵심 기능**: 다이버가 업로드한 동영상을 자동 분석해 위험지수를 산출하고, 이를 지도 위에 시각화

**결과**
2026년 제주 바이오 AX 해커톤에서 대상을 수상했습니다(2026.7.11, (재)제주테크노파크). 발표자료상 기대효과로는 다이버 참여형 데이터로 2~3년 주기 조사의 공백을 극복해 복원 골든타임을 확보하고, 연 300억원대 복원 예산의 배분 효율을 높이며, 아쿠아그린텍·삼다원 등 제주 해양바이오기업의 원료 수급 붕괴를 지연하는 효과를 제시했습니다. *(참가팀 수·심사 기준 등 경쟁 맥락을 보여줄 수치는 발표자료에 없어 별도 확인이 필요합니다.)*

**의의**
헬스케어·엔터·모빌리티 중심이었던 이전 경험을 **공공·환경(스마트시티 인접) 도메인**으로 처음 확장한 프로젝트입니다. 문제를 발굴하는 사람(기획)과 이를 구현하는 사람(AI·개발, 디자인)이 분업하면서도 하나의 위험지수 설계 논리로 수렴시킨 경험은, 여러 전문성을 통합해 하나의 솔루션으로 만드는 컨설팅 프로젝트 구조와 닮아 있습니다.

## 압축형 (글자수 제한이 있는 "활동내용" 칸용)

2026년 제주 바이오 AX 해커톤(주최: 제주테크노파크)에서 팀 '블루마린스'로 대상을 수상했습니다. 갯녹음(바다사막화)으로 제주 연안 암반의 39.53%가 훼손됐지만 조사 주기가 2~3년에 달해 복원 골든타임을 놓치는 문제를, 다이버가 일상적으로 촬영하는 수중 영상을 활용해 해결하고자 했습니다. 저는 기획을 담당해 다이빙 커뮤니티·문헌 조사로 문제를 정의하고, 수온·성게 밀도·해조류 피복률을 가중합한 위험지수 설계를 총괄했습니다(AI 모델은 팀장이, 대시보드 개발은 팀원이 담당). 그 결과 다이버 영상만으로 갯녹음을 실시간 모니터링하는 프로토타입을 완성해 대상을 수상했습니다.

## 자소서/면접 인용 시 유의사항

1. **역할을 정확히 한정할 것.** 본인은 "기획"(문제정의·조사·기획 총괄) 담당이었고, AI 모델 구축은 천주용, 프론트/디자인은 최훈석 담당입니다. "AI 모델을 직접 만들었다"처럼 서술하면 과장이 됩니다. "성게 밀도·해조류 피복률을 위험지수에 반영하는 설계 방향을 제시했다"처럼 기획자 관점의 표현이 정확합니다.
2. **데이터셋 규모(77,470장/327,690개)와 모델 성능을 혼동하지 말 것.** 이는 팀이 학습에 활용한 참조 데이터 규모이지, 완성된 모델의 정확도·정밀도 수치가 아닙니다.
3. **경쟁 맥락 정보(참가팀 수, 심사 기준) 확인 필요.** 발표자료에는 없어 추가로 확인되면 "몇 개 팀 중 대상"처럼 구체화할 수 있습니다.
4. **날짜 표기**: 본문에서는 실제 발표자료 표기(제주 바이오 AX 해커톤, 2026.7.11 수상)를 기준으로 정리했습니다.
