# 포트폴리오 프로젝트 요약본 ⑦ — 측정용 소프트웨어의 사용성 개선 (오비랩, 뇌 측정 장비)

> 작성 목적: 포트폴리오 9개 프로젝트 요약 작업의 일곱 번째. 요청대로 1분 요약 스크립트를 두괄식(결론·핵심 수치 먼저)으로 작성. 포트폴리오 원문의 "70% 감소(평균 40초)"라는 표현이 개선 전/후 중 어느 쪽을 가리키는지 모호하다는 점과, "교육 없이 가능해졌다"는 가설과 실제 측정 지표(소요시간) 사이의 간극을 스스로 짚음
> 작성일: 2026-10-02
> 근거자료: `portfolio-all-projects-hypothesis-structure.md`(포트폴리오 원문 구조화)

## 0. 설계 프롬프트

> 너는 지원자의 포트폴리오 프로젝트 "측정용 소프트웨어의 사용성 개선"을 면접에서 바로 설명할 수 있는 요약본으로 만드는 코치다. 1분 요약 스크립트는 두괄식으로 — 결론(무엇을 바꿨고 결과가 어땠는지)을 먼저 말한 뒤 배경으로 들어가라. 포트폴리오 원문 "소요 시간 70% 감소(평균 40초)"라는 표현이 개선 후 수치가 40초라는 뜻인지, 감소분이 40초라는 뜻인지 모호하다는 점을 숨기지 말고 가장 자연스러운 해석(개선 후 평균이 40초)을 쓰되 그 해석이 가정이라는 점을 밝혀라. 또한 가설("전문 교육 없이도 가능")과 실제로 측정한 지표(소요시간 감소)가 정확히 같은 것을 증명하지는 않는다는 간극을 지적하고 답변하라.

## 1. 1분 요약 스크립트 (두괄식)

> "저는 뇌 측정 장비 소프트웨어의 측정 준비 과정을 재설계해서, 사용자의 측정 준비 소요 시간을 70% 줄여 평균 40초로 단축했습니다. 배경은, 사용자 설문 20명 중 37%가 '교육을 받지 않으면 이용이 어렵다', 29%가 '장비 연결이 끊어져도 알 방법이 없다'고 답한 것이었습니다. 그래서 Primary 버튼 하나만 따라 누르면 측정 준비의 모든 과정이 완료되는 단계별 구조로 화면을 재설계하고, 장비 연결 상태에 대한 실시간 피드백을 추가했습니다. 다만 이 '70% 감소, 평균 40초'라는 수치가 정확히 개선 전/후 중 어느 쪽을 기준으로 한 표현인지는 제가 다시 짚어봐야 할 지점이고, 가장 자연스럽게는 개선 후 평균이 40초라는 뜻으로 이해하고 있습니다."

## 2. 구조화 (문제정의 → 가설 → 방법론 → 결과 → 회고)

| 단계 | 내용 |
|---|---|
| 문제정의 | 사용자 설문(20명): "교육 없으면 이용 어려움" 37%, "장비 연결 끊겨도 알 방법 없음" 29%, "마커 복수 사용 불가" 17%, "기능을 모르는 사용자 존재" 11% |
| 가설 | 이해관계자·사용자 인터뷰 인사이트를 반영해 단계별 구조와 피드백을 제공하면, 전문 교육 없이도 측정 준비를 완료할 수 있어 소요 시간이 줄어들 것이다 |
| 방법론 | Primary 버튼을 따라가며 누르면 측정 준비까지 전 과정이 완료되는 단계별 구조 설계 + 장비 연결 상태에 대한 실시간 피드백 제공 |
| 결과 | 측정 준비 소요 시간 70% 감소(평균 40초) |
| 회고(포트폴리오 원문) | 명시적 회고 없음 — 아래 3절에서 자가 회고로 보완 |

## 3. 자가 회고 (포트폴리오에 없던 부분)

이 프로젝트는 두 가지 지점에서 보완이 필요합니다. 첫째, 가설은 "전문 교육 없이도 측정 준비를 완료할 수 있다"는 것이었는데, 실제로 측정한 건 소요 시간 감소뿐입니다. 소요 시간이 줄었다고 해서 그게 곧 "교육이 필요 없어졌다"는 걸 직접 증명하지는 않습니다 — 예를 들어 숙련된 사용자가 더 빨라진 것일 수도 있고, 신규 사용자도 여전히 중간에 막혔지만 전체 평균이 줄었을 수도 있습니다. 둘째, "단계별 구조"와 "실시간 피드백"이라는 두 가지 솔루션을 동시에 적용해서, 어느 쪽이 얼마나 기여했는지는 구분하지 못했습니다. 다시 한다면, 신규 사용자만 따로 분리해 교육 없이 완료할 수 있었는지를 별도로 확인하고, 두 솔루션을 순차적으로 적용해 각각의 기여도를 나눠 보고 싶습니다.

## 4. 핵심 꼬리질문 1 — "가설은 '교육 없이도 가능'이었는데, 측정한 건 소요 시간뿐이네요. 정말 교육 없이 가능해졌는지는 어떻게 확인했나요?"

**모범답안(직접답변 우선, 간극 인정)**: "정확한 지적입니다. 제가 직접 측정한 건 소요 시간 감소뿐이고, '교육 없이도 가능했는가'를 별도로 검증하지는 못했습니다. 다만 간접적인 근거는 있습니다 — 설문에서 '교육 없으면 어렵다'고 답한 사용자들이 지적한 지점(복잡한 절차, 연결 상태를 알 수 없음)을 정확히 겨냥해서, 그 과정을 버튼 하나로 따라가는 구조와 실시간 피드백으로 바꾼 것이었습니다. 그래서 소요 시간 감소가 간접적으로는 '복잡함이 줄었다'는 신호로 해석할 수 있지만, '신규 사용자가 실제로 교육 없이 완료했는가'를 직접 확인한 건 아니라서, 이 부분은 신규 사용자만 따로 분리해 측정했어야 한다고 생각합니다."

## 5. 핵심 꼬리질문 2 — "'70% 감소, 평균 40초'가 정확히 무슨 뜻인가요? 개선 전/후 중 어느 쪽이 40초인가요?"

**모범답안(직접답변 우선, 모호함 인정)**: "가장 자연스럽게는 개선 후 평균 소요 시간이 40초라는 뜻으로 이해하고 있습니다. 다만 솔직히 말씀드리면 그 표현이 '감소분이 40초'라는 뜻인지, '개선 후 결과가 40초'라는 뜻인지가 당시 기록에서 완전히 명확하지는 않아서, 제가 이 부분은 다시 한번 정확히 확인해서 말씀드리겠습니다. 핵심은 70%라는 상대적 감소폭이 꽤 크다는 것이고, 그 절대 수치가 수십 초 단위의 짧은 작업이었다는 점입니다."

## 6. 그 외 예상 꼬리질문 2가지

### 6-1. "단계별 구조와 실시간 피드백, 두 솔루션 중 어느 쪽이 더 효과적이었는지 구분했나요?"

**모범답안**: "구분하지 못했습니다. 두 솔루션을 동시에 적용하고 전체 결과만 측정해서, 각각의 기여도를 나눠보지는 못했습니다. 다시 설계한다면 단계별 구조만 먼저 적용해 효과를 보고, 그다음 실시간 피드백을 추가해 증분 효과를 따로 측정하는 순차적 검증이 더 정확했을 것 같습니다."

### 6-2. "20명 설문이 전체 사용자를 대표한다고 볼 수 있나요?"

**모범답안**: "완전한 대표 표본이라고 주장하긴 어렵습니다. 다만 이 설문은 통계적 일반화보다 '어떤 지점에서 사용자가 막히는지' 문제를 구조화하는 탐색 단계였고, 그렇게 찾아낸 문제(교육 필요성 37%, 연결 상태 인지 불가 29%)에 대한 해결책의 효과는 이후 전체 사용자 집단의 소요 시간 측정으로 확인했습니다."
