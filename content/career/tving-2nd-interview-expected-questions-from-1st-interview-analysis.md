# 티빙 2차 면접 예상 질문 — 실제 1차 면접 질의응답 분석 기반

> 작성 목적: 실제로 치른 티빙 1차 면접의 질의응답 23개를 분석해, ① 면접관이 회의적 반응을 보이거나 더 캐물을 여지를 남긴 지점, ② 1차에서 다뤄진 주제가 2차에서 심화될 가능성, ③ 2차(임원/최종) 면접에서 전형적으로 새로 나오는 주제를 예측하고, ④ 1차-2차 간 반드시 일관되게 유지해야 할 숫자·용어를 체크리스트로 정리
> 작성일: 2026-10-13
> 근거자료: 사용자가 공유한 티빙 1차 면접 실제 질의응답 23개(강혜우가 직접 정리), 기존 세션 자료(CTR 7%p, 즐겨찾기 비율, 벡터DB 긴장 등)

## 0. 설계 프롬프트

> 너는 실제로 치른 1차 면접 질의응답 23개를 분석해서 2차(최종/임원) 면접을 준비하는 코치다. 1차에서 면접관이 직접 회의적 반응을 보이거나("샘플이 작으면 기각될 확률이 높다") 더 캐물을 여지를 남긴 지점을 최우선으로 식별하고, 그 지점에 대한 심화 질문과 더 탄탄한 답변을 준비하라. 또한 1차에서 다룬 주제(티빙 AI 에이전트 설계 등)가 2차에서 어떻게 더 깊어질지, 그리고 2차 면접에서 전형적으로 새로 나오는 주제(장기근속 의지, 컬처핏, 연봉, 90일 계획)를 예측하라. 마지막으로 1차에서 이미 특정 숫자나 설명으로 답변을 커밋했기 때문에, 2차에서 절대 바뀌면 안 되는 사실들을 체크리스트로 정리하라.

## 1. 핵심 요약 (두괄식)

1차 면접에서 면접관이 가장 날카롭게 파고든 지점은 **①통계적 유의성(작은 표본에서 p<0.01이 나온 것에 대한 노골적 회의), ②"벡터DB·온톨로지 그래프"라는 구체적 기술 스택 주장, ③PM-데이터팀 간 권한 경계**이며, 이 세 가지는 2차에서 다른 각도로 재추궁될 가능성이 매우 높습니다. 또한 1차에서 **"즐겨찾기 등록자 16%"**, **"블루밍톡(MAU 약 5천)"**, **"20명 표본"**, **"챗봇 참여도 25%는 상대 증가율"**처럼 구체적으로 이미 커밋한 사실들이 있어, 2차에서 절대 다르게 말하면 안 됩니다. 추가로 2차(최종)는 보통 **장기근속 의지, 컬처핏, 연봉·입사일, 90일 계획**처럼 1차와는 전혀 다른 축의 질문이 나올 가능성이 큽니다.

## 2. 카테고리 A — 1차에서 드러난 약점의 재추궁 예상 (최우선 대비)

### A-1. 통계적 유의성 — "작은 표본에서 유의미한 결과가 나온 게 의심스럽다"

- **1차 상황**: 5일·100명 규모에서 만족도 p<0.01, 참여도 p<0.05가 나온 것에 대해 면접관이 "샘플이 작으면 기각될 확률이 높다"는 우려를 직접 언급함 — **사실상 답변이 완전히 받아들여지지 않은 채 넘어간 지점**.
- **2차 예상 질문**: "지난번에 표본이 작은데 유의미한 결과가 나왔다고 하셨는데, 혹시 사후적으로 효과 크기(effect size)나 검정력(statistical power)을 계산해보셨나요?" / "그 결과를 지금 다시 본다면 어떻게 더 엄밀하게 검증하시겠어요?"
- **개선된 답변**:
  > "말씀하신 우려에 저도 동의합니다. 표본이 작으면 1종 오류든 2종 오류든 위험이 커지는 게 사실입니다. 다만 당시 참여도 지표(대화량)는 실험군과 대조군 간 차이가 상대적으로 커서(100문장→125문장) 작은 표본에서도 유의한 차이가 감지된 것으로 보이고, 만족도는 설문 문항 간 일관성이 높아 분산이 작았던 것으로 추정합니다. 다만 사후적으로 효과크기나 검정력 계산까지는 하지 못했다는 한계가 있고, 지금 다시 한다면 최소 표본 크기를 검정력 분석(power analysis)으로 먼저 산정한 뒤 실험을 설계하고 싶습니다."

### A-2. "벡터DB·온톨로지 그래프" — 구체적 기술 스택 심화 질문

- **1차 상황**: "데이터 수집 환경과 벡터DB·온톨로지 그래프를 구축했다"고 구체적으로 답변함 — **이미 1차에서 커밋한 사실이므로 2차에서 절대 번복하면 안 됨**. 다만 세션 내 다른 자료(`mindlogic-chatbot-llm-rag-architecture-inference.md`)에서는 이 디테일이 추론/미확정 영역으로 플래그되어 있었는데, 실제 면접에서는 이미 확정적으로 답변한 상태입니다.
- **2차 예상 질문**: "어떤 벡터DB를 쓰셨나요?" / "온톨로지 그래프는 어떤 스키마로 설계하셨나요?" / "그 둘을 어떻게 함께 활용했나요(벡터 검색 vs 그래프 탐색 역할 분리)?"
- **대응 전략**: 이미 1차에서 커밋했으므로 이번엔 피하지 말고, **한 단계 추상화된 수준에서 일관되게 설명**하는 게 최선입니다. 예: "정확한 제품명은 클라이언트사 소유 인프라라 외부에 공개하기 어렵지만, 역할 구분으로 설명드리면 벡터DB는 '아티스트가 과거에 언급한 내용 중 의미적으로 유사한 대화를 검색'하는 데, 온톨로지 그래프는 '아티스트-그룹-소속사-이벤트처럼 구조화된 관계 정보를 조회'하는 데 썼습니다. 두 방식을 조합해 실시간성이 필요한 질문엔 그래프 조회를, 뉘앙스가 필요한 질문엔 벡터 검색을 라우팅했습니다." — **이 설명은 실제 구현을 몰라도 RAG 아키텍처의 표준 패턴으로 일관되게 답할 수 있는 안전한 추상화 수준입니다.**

### A-3. PM-데이터팀 권한 경계 — 다른 사례로 재질문 가능성

- **1차 상황**: "ML 쓰자는 데이터팀과 세그먼트+명시적 긍정행동 기반 정렬을 제안해 조정"한 경험과 "모델 입출력까지 지정하면 월권"이라는 경계 기준을 답변함 — 논리는 탄탄했음.
- **2차 예상 질문**: "그럼 반대로, 데이터팀이 제안한 방향이 맞다고 생각했는데 본인이 설득당한 경험은 없나요?" (겸손함·유연성 검증형 반대 질문)
- **준비 방향**: 항상 "내가 설득한 경험"만 있으면 고집스러워 보일 수 있으니, 데이터팀·개발팀의 의견을 받아들여 본인 생각을 바꾼 사례를 하나 준비해둘 것(예: 러닝보조서비스의 B2B2C 피벗 등 — 타인의 현장 피드백을 받아들인 사례와 연결 가능).

### A-4. 지표 표기(%p vs %) — 이미 1차에서 지적받고 정정한 이력

- **1차 상황**: 면접관이 "25%는 %인가 %p인가", "CTR 10% 상승해 25.2%"라는 포트폴리오 표기를 지적했고, 본인이 "7%p가 맞다"고 정정함 — **이미 한 번 지적받은 이력이 있으므로 2차에서 재차 틀리면 치명적**.
- **체크리스트**: 챗봇 참여도=**25%(상대 증가율, 100→125문장)**, EV 추천 CTR=**7%p(18%→25%)**로 반드시 구분해서 말할 것.

## 3. 카테고리 B — 티빙 AI 에이전트 설계 주제의 심화 가능성

1차에서 라우팅 구조(CS 챗봇 vs 추천 서브챗봇), MVP 범위(콘텐츠 추천 챗봇부터, 대표 콘텐츠 위주), 성공지표(추천 CTR, 시청전환율, 시청시간), 아이돌 챗봇과의 비즈니스 도메인 차이(유희 vs 정보전달·추천)까지 상당히 깊게 다뤄졌습니다. 2차에서는 다음과 같은 **다음 단계 질문**이 예상됩니다.

- "MVP 이후에는 어떻게 확장하시겠어요?" → *준비*: 콘텐츠 추천 서브챗봇 다음으로 CS 챗봇, 이후 통합 라우터로 확장하는 단계적 로드맵을 미리 그려둘 것.
- "라우팅이 잘못돼서 구독 해지 문의가 추천 챗봇으로 잘못 가면 어떻게 되나요?" → *준비*: 폴백(fallback) 전략 — 신뢰도 낮은 라우팅은 사람에게 에스컬레이션하거나 "다른 의도이신가요?" 확인 질문을 넣는 설계를 제시할 것.
- "성공지표 세 가지(추천 CTR, 시청전환율, 시청시간) 중 하나만 오르고 나머지는 그대로면 성공인가요?" → *준비*: 세 지표의 우선순위(가장 먼저 봐야 할 건 시청전환율이고 CTR·시청시간은 보조지표라는 식)를 미리 정해둘 것.

## 4. 카테고리 C — 2차(최종/임원) 면접에서 전형적으로 새로 나오는 주제

1차는 실무진 면접으로 보이며 프로젝트 디테일·통계·기술 중심이었습니다. 2차는 보통 다음 주제가 추가됩니다.

- **장기근속 의지(더 날카롭게)**: 1차에서 이미 "4번의 이직이 모두 전문연구요원/조직불안정성 때문"이라는 구조적 설명을 상세히 했으므로, 2차에서는 "그래서 티빙에서는 왜 다를 거라고 확신하는가"를 **더 직접적으로** 물을 가능성이 높음. → `tving-long-tenure-question-critical-review-and-answers.md`에 이미 정리된 강한 답변(구조적 차이+자발적 선택) 활용.
- **컬처핏/리더십 스타일**: "팀장이나 임원과 의견이 갈리면 어떻게 하는가", "본인이 틀렸다는 걸 알았을 때 어떻게 인정하는가" 등.
- **합류 후 90일 계획**: "입사 후 첫 3개월 동안 무엇부터 하겠는가" — 구체적 온보딩 계획을 준비할 것(도메인 지식 습득 → 기존 추천 로직 분석 → 작은 개선 제안 순서로).
- **연봉·입사 가능 시점**: 현재 회사 퇴사 절차, 희망 연봉 범위를 미리 정리해둘 것.
- **"왜 당신이어야 하는가"**: 경쟁 지원자 대비 차별점 — EV충전+챗봇+헬스케어라는 세 도메인에서 모두 "추천·탐색" 문제를 다뤄봤다는 공통分母를 강조.
- **다른 회사 지원 현황**: 솔직하게 답하되, 티빙이 1순위라는 점을 분명히 할 것.

## 5. 1차-2차 간 반드시 일관되게 유지할 사실 체크리스트

| 항목 | 1차에서 말한 내용 | 2차에서도 반드시 동일하게 |
|---|---|---|
| 챗봇 서비스명 | 블루밍톡(중국 시장 아이돌 IP 챗봇) | 이 이름으로 통일 |
| 블루밍톡 MAU | 약 5,000명 | 동일하게 |
| 채팅 분석 표본 | 20명(10대 주 사용자, 보호자 동의 이슈로 모집 제한) | 동일하게 |
| 챗봇 참여도 25% | 상대 증가율(100문장→125문장) | "%p 아님"을 명확히 |
| EV 추천 CTR | 7%p(18%→25%) | "%p"로만 표현 |
| 즐겨찾기 등록자 비율 | **16%**(1차에서 이렇게 말함) | 기존 세션에서 "15%"로도 언급된 적 있으나, **이미 실제 면접에 커밋한 "16%"를 2차에서도 유지** |
| 비등록자 CTR | 3~4% | 동일하게 |
| 벡터DB·온톨로지 그래프 | 사용했다고 확정 답변 | 번복하지 말고 추상화된 설명으로 방어(위 A-2 참고) |
| 만족도/참여도 유의수준 | 만족도 p<0.01(t-test), 참여도 p<0.05(카이제곱) | 동일하게, 표본 작음 한계는 인정 |
| UNIST→포항공대 전과 사유 | 전문연구요원 TO 미보장(과기원 19학번부터) | 동일하게 |
| 티맥스 재직기간 | 2021.4~12월 | 동일하게 |
