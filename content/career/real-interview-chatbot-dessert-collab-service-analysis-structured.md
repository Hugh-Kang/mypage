# 실제 면접 질의응답 구조화 — 챗봇/건강디저트/사용량대시보드/장단점/서비스분석 + 볼트업 프로젝트 질문 템플릿

> 작성 목적: 실제로 치렀던 면접의 질의응답을 공유받아, 챗봇 프로젝트·건강 디저트 추천 플랫폼·사용량 대시보드·본인의 장단점·서비스에 대한 분석 다섯 카테고리로 구조화. 특히 프로젝트별로 질문이 전개된 "패턴"을 추출해, 추후 볼트업에서 실제 진행한 두 프로젝트(EV 충전구역 추천 고도화, U+ 제휴 쿠폰 발급 기능 추가 및 인증절차 간소화)에 같은 깊이로 질문할 때 참고 템플릿으로 사용
> 작성일: 2026-10-07
> 근거자료: 사용자가 공유한 실제 면접 질의응답 메모(마인드로직/챗봇, 건강디저트 플랫폼, 협업방식, 볼트업 지원 관련 질의응답)

## 0. 설계 프롬프트

> 너는 실제로 치렀던 면접의 질의응답 메모를 '챗봇 프로젝트', '건강 디저트 추천 플랫폼', '사용량 대시보드', '본인의 장단점', '서비스에 대한 분석' 다섯 카테고리로 구조화하는 코치다. 각 카테고리의 질문-답변을 정리된 Q&A 형식으로 재구성하되, 특히 프로젝트별 질문이 어떤 패턴(배경→핵심 메커니즘→차별화 요소→수치/데이터→운영현황→팀구성/역할→어려움 순)으로 전개됐는지 공통 구조를 추출하라. 이후 이 패턴을 볼트업에서 실제 진행한 두 프로젝트(EV 충전구역 추천 고도화, U+ 제휴 쿠폰 발급 기능 추가 및 인증절차 간소화)에 적용해, 같은 깊이로 캐물을 수 있는 예상 질문 목록을 프로젝트별로 미리 준비해두어라. 단, 이번 턴에는 질문에 답하지 말고 목록만 준비한다 — 실제 질의응답(모의면접)은 사용자가 요청하는 다음 턴에 별도로 진행한다.

## 1. 챗봇 프로젝트 (아이돌 페르소나 챗봇, 마인드로직 — 실제 질의응답)

| 질문 | 답변 요지 |
|---|---|
| 성과가 있거나 역량을 잘 발휘한 프로젝트는? | 아이돌 챗봇의 배경과 주요 기능/결과 설명 |
| 챗봇의 원천이 되는 정보는 어떻게 구성되는가? | 아이돌이 직접 입력, 매니저도 입력 가능한 환경 기획 (면접관: "아티스트에게서 정보를 얻기 위한 챗봇이네요" → 맞음, 아티스트가 직접 팬들에게 메시지도 보냄) |
| 기획자로서 경계가 모호할 텐데, 기술적 방향 제안·설계 역할은 어떻게 했는가? | 프롬프트 엔지니어링 일부 참여, LLM 모델 선정을 위한 정량/정성 기술·사용성 평가 진행 |
| 팬들이 아티스트가 아닌 챗봇과 대화한다는 걸 인지하는가? | 맞음. 메시지 버블 색상으로 구분, AI 챗봇임을 분명히 해 몰입감을 높임 |
| 아티스트마다 말투 느낌이 다를 텐데 어떻게 설정했는가? | 페르소나 설정 가능한 20가지 요소 설계(이모지 사용빈도, 말투 어미, MBTI 등). 기존 버블 서비스의 실제 아이돌 말투를 수집·유사 성격끼리 그룹화한 뒤 가장 적합한 아이돌과 매칭해 추가 학습 |
| 서비스 매출은 어떻게 되는가? | 구독료+추가 메시지 과금(월 9,900원에 300건, 초과 시 추가결제). LLM API 토큰비용 때문에 마진율 낮음 → 굿즈·앨범 판매(위버스 사례)로 다른 항목 수익 확보 (면접관: "결제 상품 구매도 가능하네요" → 맞음) |
| 마인드로직이 클라이언트 의뢰를 받아 진행한 거네요? | 맞음 |
| 실제 버블 서비스인가요? | 아니오, 중국 전용 오픈 서비스. 버블은 설명을 위한 예시였음 |
| 챗봇이 이미지나 영상을 보내나요? | 정해진 이미지는 가능, 영상은 미성년자 멤버라 검열을 엄격히 진행. 프로필 사진은 자유롭게 변경 가능 |
| 프로젝트 진행 시 가장 어려웠던 점은? | 없는 것을 새로 만드는 것 자체가 어려움 → MVP로 빠르게 베타 출시 후 발전시키는 게 중요하다고 느낌 |
| "없다"는 게 기술적으로 부족했다는 의미인가? | 아니오, AI 챗봇 활용 아이돌-팬 소통 플랫폼 자체가 업계에 없었다는 의미(네이버웹툰 캐릭터 챗봇도 있었지만 실패) |
| (별도 블록) 챗봇이 어떤 서비스인가? | 버블을 예시로 들어 문제 해결을 위해 AI 챗봇을 활용한 서비스, 비즈니스 모델 간략 설명 |
| 실제 고객 반응은 어땠는가? | 실제 아이돌이 들어왔을 때 반응이 더 좋지만 AI 챗봇도 반응 좋았음. 팬문화 자체가 "기형적"이라 아이돌의 사소한 모든 것을 알고 싶어함 |
| 챗봇인 것을 공개하는가? | 메시지 버블 색상으로 구분 |
| 여기서 가장 크게 배운 것은? | 서비스 기획 자체는 이전에도 많이 해봤지만, 이해관계자(해외 협력사 포함)와 소통하며 체계를 잡고, 그들의 의도를 파악해 우선순위대로 기능을 기획·적용하는 법을 배움 |

## 2. 건강 디저트 추천 플랫폼 (실제 질의응답)

| 질문 | 답변 요지 |
|---|---|
| 추가로 소개해줄 프로젝트는? | B2C 플랫폼 성격의 건강 디저트 추천 서비스, 배경과 기능 설명 |
| 건강디저트의 "접근성이 낮다"는 건 플랫폼 접근성인가, 상품 추천인가? | 둘 다. 구매 기회 자체가 없고 온라인에서도 뭘 사야 할지 모름 — 100명 설문+주관식 의견으로 확인. 기준은 타 플랫폼·건강디저트 상품 200~300개를 보며 공통 키워드를 분석. 이후 데이터가 없어 크롤링으로 상품·리뷰 데이터를 확보 |
| 회원가입 시 사용자 인풋을 수집하네요? / 실제 추천 전환율·메트릭은 괜찮았나? | 맞음. 초기(회원 200~300명)라 모수는 적었지만 주요 세그먼트에서는 전환율이 낮지 않았음. 단 4개 세그먼트 중 애매한 1개 그룹은 전환율이 낮게 나와, 보완 기능 추가 로드맵까지 설계 |
| 더 이상 운영하지 않는가? | 다른 인원들이 고도화 중, 본인은 작년까지만 참여 |
| 건강디저트를 찾는 사람들은 어떤 사람들인가? | 70~80%가 근성장·다이어트 관심층. '헬시플레저' 욕망을 건드리는 방향으로 기획 |
| 목적에 맞게 제품을 추천하는 거네요? | 맞음. 1차로 접근성을 높이는 추천을 제공, 탐색 단계에서는 맛·식감·당도를 파악할 수 있는 배지를 추가 |
| 가격 측면에서 관여도가 높지 않을 수 있겠네요? | 제빵사 친구들 말로는 재료비·시간 때문에 비쌈. 그래도 오프라인보다 온라인이 저렴해 온라인 구매를 유도하는 방향으로 설정, 결제수수료로 BM 설계 |
| 가격보다 더 중요한 요소는(맛/식감 등)? | 시각적인 사진이 가장 컸음 — 잘 나온 사진의 조회수가 높아, 이후 썸네일에 반영 |
| 기획은 혼자 진행했는가? | 혼자 시작, 후반에 인력 부족으로 1명 추가 합류 |
| 지인들끼리 했는가? | '홀라'라는 플랫폼을 통해 모여 진행 |
| 누가 리딩하는가? | 처음 만든 사람(본인)이지만 다들 취준생이라 초기 기준·서비스 방향성을 정리하는 역할을 맡음. 이후 이탈률 퍼널 구축도 배워 회사 업무에도 적용 |
| 기획자는 요구사항을 녹여 사용자에게 전달하는 과정도 중요한데, 어떤 과정으로 업무에 참여했는가? | 워터폴·스프린트 둘 다 경험, 2주 단위 스프린트로 진행. 우선순위와 이유를 디자이너·개발자·QA에게 소개, KPI 회고를 항상 진행 |

## 4. 본인의 장단점·성향

| 질문 | 답변 요지 |
|---|---|
| 같이 일하고 싶은 동료는? | 건설적인 피드백을 할 수 있는 동료 |
| 같이 일하기 힘든 동료는? | 건설적 피드백을 못하고, 주장에 근거가 없는 동료 |
| 그런 사람들은 어떻게 설득하는가? | 최대한 정량적인 자료를 기반으로 설득 |
| 정량적 자료가 없으면 어떻게 설득하는가? | 각자의 배경을 이해하고 설득(프로그레스바 관련 디자이너·개발팀 의견차를 좁혔던 경험) |
| 서비스기획자로서 꿈은 무엇이고 어떻게 성장하고 싶은가? | 업무적으로는 서비스 1등, 인간적으로는 선한 영향력을 주는 사람 |
| 사회적 관계에서는 어떤 사람인가? | 감성적인 보더콜리 |
| MBTI는? | ESFJ·ESTJ (면접관: "감성은 아니지 않냐" → 일할 때는 TJ, 친구들과는 F) |
| 자유로움을 추구하는 편인가, 조직 로열티를 중시하는 편인가? | 둘 다 상황에 따라 — 규율을 지키면서 그 안에서 창의성을 발휘 |
| (다소 자유로워 보이는데) 목표·성과지향적인 사람들과 마찰은 없는가? | 대학원이라는 보수적·규율 중시 환경에서도 다양하게 조사·고민해 성과를 낸 경험. 체계를 따르며 할 수 있는 것을 하는 게 자연스러움 — "자유롭게 일하고 싶으면 창업해야죠" |
| 기획도 프론트/백엔드 성향이 나뉘는데 어느 쪽인가? | 백엔드에 더 가까움 — 볼트업은 이미 사용성 개선이 많이 됐으니, 락인 요소 기획·혁신적 기능 추가가 필요하다고 판단 |
| 외국 경험이 있는가? | 호주 워킹홀리데이 1년(세일즈 업무+봉사) |
| 특정 분야 전문가가 되길 원하는가(예: AI 전문가, 전기차충전산업 전문가)? | 관심 분야가 생기면 하나를 파는 스타일 — "이 분야만 할 것"이 아니라 "이 분야를 위해 내가 할 수 있는 게 뭘까"로 접근해 기능·기획 능력을 넓힘(오비이랩→AI 챗봇 스타트업 전환 사례) |
| 관심 있는(덕질하는) 분야는? | 취미로 춤·힙합, 산업적으로는 본인이 직접 쓰는 서비스를 좋아함(제주 여행 중 전기차 렌탈 경험으로 EV 충전에 관심이 생김) |
| 입사 만 2년이 안 됐고 팀워크도 중요한데, 참을성·인내력은 어떤가? | 불법적인 업무가 아니면 다 맡아서 할 수 있음. 대학원(보수적 집단)에서도 졸업했고, 이전 2년반 다닌 회사(볼트업과 규모·구성 유사)에서 대기업 출신 책임자들의 조언을 받으며 4건의 서비스를 출시한 경험을 적합성 근거로 제시 |
| 불법적인 일만 아니면, 몇 년이나 버티겠는가? | 한 번 들어가면 10~20년 다니고 싶음 (면접관: "젊은 친구 같지 않다" → 대기업에서 일해보고 싶어 LG U+ 볼트업을 선택) |

## 5. 서비스에 대한 분석 (EV 충전 사업 전반 — 볼트업 지원 관련 실제 질의응답)

|---|---|
| 오비이랩은 어떤 회사인가 / 데이터를 다루는가? | 생체 데이터 측정 장비 회사 / 네, 데이터를 다룸 |
| 전문연구요원인가? | 대체복무 진행 |

| 직접 그림 그리고 편집 가능한가? | 와이어프레임을 직접 모두 그림 |
| 전기차 충전 사업은 어떤 사업인가? 본인이 뭘 잘할 수 있을지 생각해본 것은? | 압도적 1등이 없는 시장 — 그 요인을 분석하고 이를 건드리는 기능을 추가·런칭하고 싶어 지원 |
| 그 기능이 무엇일까요? 접근성을 이길 경쟁포인트는? | 사용자 경험의 편리함, 가격 경쟁력. 주기적으로 방문하는 위치(교회 근처 쇼핑몰 등) 공략, 프랜차이즈와 협업해 할인쿠폰으로 방문 선순환 유도(테슬라의 식당 연계 사례 참고) |
| 서비스기획자에게 중요한 역할은? | 매출을 끌어올리는 것 — 어떤 KPI를 볼지, 어떤 문제를 정의해 기능을 넣을지 보고, 리서치·이해관계자 설득·개발 관리까지 수행 |
| 매출을 올리기 위해 했던 경험은? | 챗봇 사용자의 대화 참여도를 25% 향상시킨 경험 — 구독+메시지 과금 BM과 연결해 설명 |
| 데이터에 관심이 많으시네요? | 맞음. 다만 "생각"이 항상 정답은 아니라고 봄 — HCI 연구실 경험상 사용자가 말하는 기능과 실제 필요한 기능이 다른 경우(인터뷰에서는 a,b인데 데이터는 b,c)가 있어 데이터를 흥미롭게 봄 |
| 볼트업의 고객 경험을 재고하려면 어떤 서비스를 만들겠는가? | 문제 정의와 사용자 범위 설정 → 시나리오 단계로 접근 |
| 고객 의견을 파악하기 위해 현장에 나가본 경험은? | 뉴로피드백 게임 프로젝트에서 학원업체 7곳 방문(ADHD 학생 대상 게임을 일반 학생으로 확장 목적). 현장 조사 결과 "콘텐츠 흥미도 저하"가 문제였음을 발견해 새 캐릭터·맵을 추가해 리텐션 유도 |
| 여러 전공을 거쳤는데 꿈이 무엇인가, 어떻게 성장하고 싶은가? | 업무적으로는 서비스 1등, 인간적으로는 선한 영향력(4절과 동일 답변 재확인) |
| 볼트업을 어떻게 알고 지원했는가? 가장 하고 싶은 것은? | 제주 여행 중 직접 사용하며 알게 됨. LG U+ 인프라를 활용한 기능 기획을 해보고 싶음. 초반 대비 하반기 사용성이 많이 개선된 걸 확인했고, 카카오모빌리티 카카오내비 서포트 등을 보고 활용 가치를 판단 |
| 서비스기획자로서 성장하면서 (사회인으로서) 꿈은? | ① 서비스를 1등 기업으로 만들고 싶음, ② 사용자경험을 혁신하고 싶음 — 주유(2~3분)와 충전(30분~1시간)의 시간 차이를 재미있거나 편리하게 바꾸고 싶어 흥미를 느낌 |
| 트래픽을 6개월 내 20%, 매출을 20% 올리라면 무엇을 확장하고 싶은가? | 기존 사용자 업셀링 또는 다른 섹터에서 파이 확보 — 프랜차이즈 협업 기능 기획 |
| 단순 세일즈는 그렇다 치고, 트래픽(MAU)은 어떻게 올리나? | 혼잡도 예측 기능과 맥락 분석 기반 추천 |
| 체류시간은 어떻게, 왜 올려야 하나? | 광고 사업을 위해 체류시간이 필요 — 현재 오픈채팅방에서 하는 커뮤니티 기능을 앱으로 가져와, 콘텐츠 제공+참여 보상으로 리텐션 선순환을 만들어야 함 |
| 회사가 2~3년차라 미흡한 점이 많아 내부시스템·충전기 설치절차 관리·재고관리 시스템에 투입될 수도 있는데 괜찮은가? | 가능함 — 스타트업·연구실 근무 경험과 유사. 노가다성 작업, 규제·특허 검토 등으로 이미 잔뼈가 굵었음 |
| 가장 퍼포먼스가 잘 나왔던 환경은? | 활용할 데이터가 많을 때(챗봇 프로젝트에서 협력사가 적극 협조해 데이터 수급이 원활했던 사례) |
| 데이터도 중요하지만 오프라인도 함께하는 사업인데, 데이터분석 결과와 현장(영업사원·구축담당자) 의견이 충돌하면 어떻게 해결하나? | 현장의 말에 더 귀 기울임 — 뉴로피드백 게임 사례처럼, 리서치를 충분히 마친 뒤에도 현장에서 새로운 문제를 발견할 수 있어 리서치+현장 의견을 함께 반영해야 함 |
| 볼트업의 본질은 무엇이고, 다음 레벨에서 집중해야 할 것은? | 플랫폼 — 익숙한 환경에 차별점이 하나 있어야 사람들이 흥미를 갖고 참여함 |

## 6. 질문 패턴 템플릿 — 챗봇·건강디저트 질문이 전개된 공통 구조

위 1·2절(챗봇, 건강디저트)을 보면, 면접관은 프로젝트마다 거의 동일한 순서로 깊이를 더해가며 캐물었습니다. 이 패턴을 추출하면 다음과 같습니다.

1. **배경·문제정의 확인**: "이 프로젝트는 왜 하게 됐는가, 어떤 문제를 풀려 했는가"
2. **핵심 메커니즘 세부 질문**: "그 기능/정보가 실제로 어떻게 구성·작동하는가" (예: 챗봇 정보 원천, 접근성의 정확한 의미)
3. **기획자 역할의 경계 질문**: "기술적인 부분은 어디까지 직접 관여했는가"
4. **사용자 인지·신뢰 질문**: "사용자가 이 사실(챗봇임, 데이터 수집 등)을 인지하고 있는가"
5. **차별화 요소의 디테일 질문**: "이걸 어떻게 다르게/세분화해서 설계했는가" (페르소나 20요소, 맛·식감·당도 배지)
6. **수치·BM 질문**: "매출 구조는 어떻게 되는가, 전환율·메트릭은 어땠는가"
7. **운영 현황 질문**: "지금도 운영되고 있는가, 누가 이어받았는가"
8. **타겟 고객 특성 질문**: "이 서비스를 쓰는 사람들은 어떤 사람들인가"
9. **부차 요소의 중요도 재확인 질문**: "가격보다 더 중요했던 요소는 무엇이었나"
10. **팀 구성·리더십 질문**: "혼자 했는가, 누가 리딩했는가"
11. **업무 프로세스 질문**: "워터폴/스프린트 중 무엇으로, 이해관계자와는 어떻게 소통했는가"
12. **어려웠던 점 + 명확화 재질문**: "가장 어려웠던 점은?" → "그게 기술적 어려움이었나, 다른 의미였나?"

## 7. 이 템플릿을 볼트업 두 프로젝트에 적용한 예상 질문 (답변은 아직 준비하지 않음 — 다음 모의면접용)

### 7-1. EV 충전구역 추천 고도화

1. (배경) 이 추천 기능은 왜 고도화하게 됐나요? 원래 어떤 문제가 있었나요?
2. (메커니즘) 추천 로직이 실제로 어떤 데이터를 기준으로 어떻게 작동하나요? (즐겨찾기, 최근 사용, 거리 등 어떤 신호를 어떤 순서로 쓰나요?)
3. (역할 경계) 이 로직을 실제로 구현할 때, 기획자로서 어디까지 직접 설계하고 어디서부터는 개발자에게 넘겼나요?
4. (사용자 인지) 사용자는 추천 순서가 "자신의 즐겨찾기 때문에" 바뀐 걸 인지하나요, 아니면 그냥 자연스럽게 받아들이나요?
5. (차별화 디테일) 즐겨찾기 등록자/미등록자 외에, 충전 빈도·충전량·방문 시간대처럼 더 세분화한 기준은 왜 이번엔 적용하지 않았나요?
6. (수치/BM) 이 추천 기능이 실제로 충전 매출이나 충전 시작 전환(CVR)에 얼마나 기여했다고 보시나요?
7. (운영 현황) 지금도 이 추천 로직을 직접 담당하고 있나요, 아니면 다른 분이 이어받았나요?
8. (타겟 고객) 이 추천 기능을 가장 많이 쓰는 사용자는 구체적으로 어떤 특성을 가진 사람들인가요?
9. (부차 요소) CTR 외에, 추천 순서를 바꿨을 때 사용자들이 체감한 다른 변화(불만, VOC 등)는 없었나요?
10. (팀 구성) 이 고도화는 혼자 기획했나요, 아니면 몇 명이 함께했나요? 각자 역할은요?
11. (프로세스) 이 기능을 출시할 때 어떤 절차(스프린트, 우선순위 논의, QA)를 거쳤나요?
12. (어려움 + 재질문) 가장 어려웠던 점은? → 그게 데이터가 없어서였나요, 아니면 다른 이유였나요?

### 7-2. U+ 제휴 쿠폰 발급 기능 추가 및 인증절차 간소화

1. (배경) 이 쿠폰 발급 기능은 왜 추가하게 됐나요? 기존엔 어떤 문제가 있었나요?
2. (메커니즘) 쿠폰 발급의 인증 절차가 구체적으로 어떻게 간소화됐나요? (기존 단계 수 대비 몇 단계로 줄었나요?)
3. (역할 경계) 인증 절차나 쿠폰 로직 설계에서, 기획자로서 보안·정책 측면까지 직접 설계했나요, 아니면 LG U+ 쪽 정책을 그대로 반영한 건가요?
4. (사용자 인지) 사용자는 이 쿠폰이 "LG U+ VIP 멤버십 제휴 혜택"이라는 걸 명확히 인지하나요?
5. (차별화 디테일) 이 쿠폰은 모든 사용자에게 동일하게 발급되나요, 아니면 등급·조건별로 다르게 설계됐나요?
6. (수치/BM) 이 쿠폰 기능이 실제 매출(앞서 언급한 16%)과 휴면회원 복귀(14%)에 기여했다고 했는데, 쿠폰 발급 건수 대비 실제 사용률은 어느 정도였나요?
7. (운영 현황) 이 쿠폰 발급 기능은 지금도 같은 방식으로 운영되고 있나요, 아니면 이후에 바뀌었나요?
8. (타겟 고객) 이 쿠폰을 주로 쓰는 사용자는 신규 가입자인가요, 기존 휴면 회원인가요?
9. (부차 요소) 쿠폰 발급·사용 과정에서 CS나 VOC로 들어온 불편 사항은 없었나요?
10. (팀 구성) 이 기능은 카카오모빌리티 쪽 기획자들과 어떻게 역할을 나눠 진행했나요?
11. (프로세스) 보안·정책이 걸린 기능이라 의사결정 승인 절차가 더 길었을 텐데, 어떤 절차를 거쳤나요?
12. (어려움 + 재질문) 가장 어려웠던 점은? → 그게 기술적 제약(토큰 만료 등)이었나요, 아니면 LG U+·카카오모빌리티 간 정책 조율의 어려움이었나요?

## 8. 다음 단계 안내

이 문서의 7절 질문 목록은 아직 답변이 준비되지 않은 "질문만" 정리된 상태입니다. 사용자가 "이 질문들로 모의면접 시작하자"고 요청하면, 이 7-1·7-2 목록을 순서대로 사용해 실전처럼 질의응답을 진행하면 됩니다.
