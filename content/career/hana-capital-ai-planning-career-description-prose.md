# 하나캐피탈 AI 기획 — 경력기술서 초안 (Word용 줄글, 검토 반영본)

> 근거: 지원자가 작성한 역량 중심 경력기술서 초안 + 검토 피드백 반영
> 성격: Word 문서에 그대로 옮겨 붙일 수 있는 최종 줄글 초안
> 작성일: 2026-08-30

## 반영한 수정 사항

1. **RAG·Vector DB·오답률(18%→7%) 키워드 복원** — 이 공고가 명시한 우대 기술(챗봇, STT/TTS, RAG) 중 하나가 통째로 빠져 있어 되살림
2. **통계 검정 방식 정정** — 참여도(chi-square, p<0.05)와 만족도(t-test, p<0.01)를 각각 맞는 검정에 연결
3. **회사명·기간 태그 추가** — 각 섹션 제목 옆에 괄호로 짧게 표기해 이력서와 대조 가능하도록 함
4. **6개 국어 자동 번역 기능** — 실제 수행 사실 확인되어 그대로 유지

## 경력기술서 초안

### 경력 목표

AI를 통해 업무 효율과 고객 경험을 동시에 혁신하는 기획자를 지향합니다. 특히 LLM 기반 서비스 기획 시, 개선 성과를 단순한 정성적 만족도에 그치지 않고 통계적으로 검증 가능한 정량 지표로 입증하는 것을 목표로 합니다.

### LLM 서비스 기획 및 검증 역량 (마인드로직, AI Product Manager, 2024.04–2025.05)

AI 챗봇 스타트업에서 데이터 수집 및 전처리 파이프라인을 구축해 학습 데이터를 확보했습니다. 매니저와 AI가 대화 주제별 정보를 유기적으로 확장할 수 있도록 구조화하여 챗봇의 프롬프트와 컨텍스트를 설계했고, 수집된 데이터를 일반 DB와 Vector DB에 이원화 저장한 뒤 RAG로 응답에 필요한 정보만 조회(fetch)하도록 구성해 정확도와 반응속도·비용을 함께 최적화했습니다. 그 결과 응답 오류(할루시네이션)율을 18%에서 7%로 낮췄습니다. 개선 성과는 대화 참여도(Linguistic/Interaction cue, chi-square test p<0.05)와 만족도(t-test p<0.01)를 각각 정량 지표로 정의해 AB 테스트로 검증했으며, 대화 참여도 25%, 만족도 30% 향상을 이끌어냈습니다.

### 최소 공수로 비효율을 해결 (마인드로직 / 볼트업)

기획자가 개발자를 거치지 않고 서비스 화면 텍스트를 직접 수정할 수 있는 언어 패키지 환경을 구축했습니다(마인드로직, 2024.04–2025.05). 이를 통해 내외부 협업 인원(14인)의 커뮤니케이션 리소스를 줄였으며, LLM API를 연동한 6개 국어 자동 번역 기능까지 도입해 운영 공수를 최소화했습니다.

전기차 충전 플랫폼에 카카오T 결제 기능을 연동하는 과정에서는(볼트업, 2026.03–현재), 파트너사의 '1:1 계정 제한' 요구와 '사용성 유지'가 충돌하는 문제를 시나리오 단위의 정책 재설계로 풀어냈습니다. 추가 개발 없이 문제를 해결하여 파트너사가 우려한 관련 CS를 월 평균 0건으로 유지 중입니다.

### 데이터와 피드백 기반의 사용자 분석 역량 (오비이랩 / 볼트업)

데이터와 사용자 VoC를 교차 검증하여 서비스를 고도화합니다.

뇌 데이터 분석 서비스에서는(오비이랩, 2021.12–2024.03) 퍼널 분석으로 이탈 밀집 구간을 특정하고, 사용자 인터뷰를 거쳐 맞춤형 튜토리얼을 도입함으로써 해당 구간의 이탈률을 70%에서 26%로 낮췄습니다.

전기차 충전 플랫폼에서는(볼트업, 2026.03–현재) 즐겨찾기 등록 여부에 따른 추천 CTR 격차를 데이터로 확인한 후, VoC 피드백을 반영해 추천 우선순위를 재설계했습니다. 그 결과 CTR 7% 향상 및 관련 VoC 47% 감소라는 성과를 거두었습니다.
