# 현대자동차그룹 2026년 신년사 — 키워드 도출 및 구조화

> 성격: 정의선 회장 2026년 신년사(2026.01.05) 조사 및 핵심 키워드 구조화

## 0. 설계 프롬프트

> 당신은 자동차 산업 전문 리서처입니다. 현대자동차그룹 정의선 회장의 2026년 신년사를 조사해, 실제 인용된 문장을 근거로 핵심 키워드를 도출하고, 신년사 전체를 "위기 진단 → 대응 방향 → 실행 축"이라는 구조로 재구성하세요. 추측하지 말고 검색된 기사에 실제 인용된 발언만 근거로 삼고, 각 키워드가 어떤 맥락에서 나왔는지 명시하세요.

## 1. 개요

- 일시: 2026년 1월 5일, 현대자동차그룹 신년회(온라인 개최)
- 참석: 정의선 회장 및 주요 경영진
- 전체 톤: 2026년을 "위기 요인이 현실화되는 해"로 규정하고, 성찰과 체질개선, 민첩한 의사결정을 최우선 과제로 제시

## 3. 메시지 구조화 — 위기 진단 → 대응 방향 → 실행 축

```
[진단] 2026년은 위기 요인이 현실로 다가오는 해
    │  (글로벌 공급망 재편, 경기 둔화, 경쟁 심화)
    │
    ├─ [대응축 1] 성찰을 통한 체질개선
    │     ├─ 고객 시각이 충분히 반영되었는가 (제품·기획·개발 과정 자문)
    │     ├─ 품질에 대해 고객 앞에 떳떳한가
    │     └─ 근원적 경쟁력(차량 품질, 고객지향 서비스) 극대화
    │
    ├─ [대응축 2] 일하는 방식의 혁신
    │     ├─ 본질 추구 — 숫자·자료를 넘어 현장·사람을 직접 확인
    │     ├─ 빠르고 명확한 의사소통
    │     └─ 형식에 얽매이지 않는 민첩한 의사결정
    │
    ├─ [대응축 3] 도전과 재도전의 조직문화
    │     ├─ 변화는 선택이 아니라 생존
    │     └─ 실패를 두려워하지 않고 다시 시도하는 문화
    │
    ├─ [대응축 4] 생태계 확장과 협력
    │     ├─ 공급 생태계 동반자 지원 확대
    │     └─ 다양한 파트너와의 과감한 협력 → 산업·제품의 새 기준 선도
    │
    └─ [대응축 5] 미래 기술 내재화
          ├─ AI = 범용지능기술, 생존의 문제 → 피지컬 AI(차·로봇·제조 데이터 결합)
          ├─ SDV 전환 재확인
          └─ 로보틱스 내재화(보스턴다이내믹스 협업)
```

## 4. 참고: Feature&SW서비스 지원과의 접점 (참고용)

지원 중인 "Feature & SW 서비스 사업 기획/개발" 직무와 특히 맞닿는 키워드:
- **고객 관점·품질에 대한 정직함** → Feature UX 트랙의 "사용자리서치·사용성평가를 통한 UX 검증·개선"과 같은 결의 메시지
- **본질 추구(현장·사람 확인)** → 데이터만이 아니라 실사용자 인터뷰·관찰조사를 중시하는 지원자의 방법론과 연결 가능
- **과감한 협력(파트너십)** → SW서비스 사업 트랙의 "글로벌 파트너십 구축·사업협력"과 직접 연결
- **AI·SDV·피지컬AI** → SDV플랫폼 및 서비스기획 트랙, Pleos Connect/Gleo AI 등 이전 조사 자료와 연결

단, 신년사 문구를 자소서에 직접 인용할 때는 과도하게 티 나는 "짜깁기"처럼 보이지 않도록, 표현을 그대로 베끼기보다 회사가 추구하는 방향과 본인 경험의 접점을 자기 언어로 재서술하는 것을 권장.
