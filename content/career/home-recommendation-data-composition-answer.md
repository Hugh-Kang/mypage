# 홈화면 충전구역 숏컷 고도화 — 추천시스템 데이터 구성 답변 (개요/문제정의/목적/데이터/분석/통찰/결과/의의)

## 0. 설계 프롬프트

> 너는 이 세션에서 이미 검증된 홈화면 추천 프로젝트의 모든 사실(문제정의, VoC, A/B 테스트 표본·유의성 검증, CTR 성과, 매출 기여의 한계)을 근거로, "추천시스템을 위한 데이터 구성이 어떻게 되었는지"를 개요-문제정의-목적-활용데이터-분석내용-통찰-결과-의의의 8단계로 구조화한 완결된 답변을 작성하라. 문서마다 다르게 나타난 즐겨찾기 사용자 비율(16%/18%) 같은 아직 확정 안 된 수치는 단정하지 말고, 대신 이미 여러 문서에서 일관되게 확인된 절대값(3만 명, 15,000/15,000 분할)을 중심으로 서술해 불필요한 리스크를 피하라.

## 1. 개요

전기차 충전 플랫폼(볼트업) 홈 화면에 노출되는 "추천 충전구역 숏컷" 기능의 추천 로직을 데이터 기반으로 재설계한 프로젝트입니다.

## 2. 문제정의

사용자가 특정 충전구역을 즐겨찾기까지 등록해뒀는데도, 홈 화면 추천에는 엉뚱한 충전구역이 먼저 노출되고 있었습니다. 그 결과 오히려 자주 이용하는 "단골" 사용자일수록 홈 화면 추천을 신뢰하지 못하고 매번 다시 검색해야 하는, 앞뒤가 안 맞는 문제가 있었습니다.

## 3. 목적

사용자가 원하는 충전구역을 추가 탐색 없이 바로 찾아 이용할 수 있도록, "즐겨찾기 등록 여부"를 추천 우선순위의 최우선 조건으로 반영해 추천의 실질적 적중률(CTR)을 높이는 것이 목적이었습니다.

## 4. 활용한 데이터

| 데이터 유형 | 구체적 내용 | 활용 목적 |
|---|---|---|
| 사용자 행동 데이터(Explicit) | 충전구역 즐겨찾기 등록 여부 | 추천 우선순위의 최우선 조건으로 반영 |
| 사용자 특성 데이터 | 충전 빈도, 충전량, 지역, 연령대 | A/B 테스트 실험군·대조군 간 공변량 균형화(특정 그룹에 유리한 조건이 몰리지 않게) |
| 홈 화면 클릭 로그 | 추천 노출 대비 클릭 여부 | CTR 계산(핵심 성과 지표) |
| 충전 이벤트 로그 | 추천 선택 이후 실제 충전 시작·완료 여부 | 추천이 실제 행동(충전 완료)까지 이어졌는지 검증 |

## 5. 분석 내용

즐겨찾기를 등록한 사용자 집단을 대상으로, 실험군·대조군 각 15,000명씩(총 약 3만 명)으로 무작위 분할한 A/B 테스트를 설계했습니다. 이때 충전 빈도·충전량·지역·연령대가 두 그룹에 고르게 분포되도록 공변량을 맞췄습니다. 개선된 알고리즘(즐겨찾기 최우선 노출)을 적용한 실험군에서 CTR이 더 높게 나타났고, 카이제곱 검정으로 이 차이가 p<0.01 수준에서 통계적으로 유의미함을 확인한 뒤 전체로 확장 적용했습니다.

## 6. 통찰

즐겨찾기를 등록한 사용자는 특정 충전구역을 반복적으로 이용하는 행동 패턴을 보이는데, 기존의 다중 조건 조합 우선순위 로직에는 이 "반복 이용 패턴"이 최우선 조건으로 반영되어 있지 않았습니다. 오히려 이용 빈도가 높은 사용자일수록 추천과 실제 필요 사이의 괴리가 커지는 역설적 상황이었고, 이 통찰을 바탕으로 즐겨찾기 여부를 최우선 조건으로 삽입하는 방향으로 로직을 재설계했습니다.

## 7. 결과

- CTR 18% → 25%로 7%p 향상 (목표치 20%를 초과 달성)
- 추천 충전구역을 선택한 이후 실제 충전 완료율은 95%에 육박 — 추천이 클릭에서 그치지 않고 실제 행동으로 이어졌음을 보여주는 지표
- 관련 VoC(문의·불만) 47% 감소

## 8. 의의

전기차 충전은 거주지 기반의 반복적 이용 패턴이 강해 이 개선이 신규 매출을 직접 창출하지는 않았지만, 사용자가 원하는 것을 추가 탐색 없이 찾을 수 있는 최소 조건을 확보했다는 점에서 사용성 개선의 가치가 명확했습니다. 또한 가설 수립 → 무작위 대조군 A/B 테스트 → 통계적 유의성 검증 → 전체 확장이라는 절차를 거쳐, 추측이 아닌 데이터로 인과관계를 검증하고 의사결정한 사례라는 점에서 방법론적 의의가 있습니다.

## 참고 — 아직 확정되지 않은 수치

즐겨찾기 등록자의 정확한 비율은 이전 모의면접 기록마다 16%와 18%로 다르게 언급되어 있어(`mock-interview-parkjinhyeong-structured.md` 4절 참고), 이 답변에서는 비율 대신 여러 문서에서 일관되게 확인된 절대값(3만 명, 15,000/15,000 분할)만 사용했습니다. 실제 면접 전에 정확한 비율을 확인해서 통일해두는 것을 권장합니다.
